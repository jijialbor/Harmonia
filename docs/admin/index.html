Harmonia Admin

Changes are saved straight to the website's GitHub repository. Only someone with a GitHub access token for that repository can make changes.

How do I get an access token?
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token. Under Repository access, choose Only select repositories and pick this website's repository.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Nothing else is needed.
  4. Generate, copy the token, and paste it here. Never share it or put it inside the website files.
